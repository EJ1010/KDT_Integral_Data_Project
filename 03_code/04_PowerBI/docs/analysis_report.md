# 치이카와 인스타그램 데이터 진단 및 키워드 분석

## 1. 데이터 구조와 품질

- 원본은 **12,534행 × 7열**이며, 컬럼은 `post_id, description, media_type_id, post_url, created_at, like_count, comment_count`이다.
- 수집 기간은 **2014-08-20 ~ 2026-10-27**다. 날짜 파싱 실패는 0건이다.
- 결측은 본문 138건(1.10%), 좋아요 1,718건(13.71%)이다.
- `post_id`와 `post_url` 중복은 없고 완전 중복행도 없다. 그러나 정규화한 본문은 중복 초과분이 374건이며, 중복군에 포함된 행은 498건이다.
- 본문 길이 중앙값은 141자, 평균은 206.0자다. 한국어가 포함된 게시물은 12,145건(96.9%)이다.
- 해시태그 포함 9,378건, URL 포함 357건, 광고·협찬 표식 포함 126건이다.
- 2020년 이전 행이 343건이고, 치이카와/먼작귀를 명시한 본문은 8,205건(65.5%)이다. 모호한 캐릭터명 검색이나 비관련 콘텐츠가 섞였을 가능성을 표본 검수해야 한다.
- 2026년 데이터가 7,760건으로 전체의 61.9%를 차지하고, 2025년은 1,450건이다. 월별 그래프의 2026년 급증은 실제 인기 상승뿐 아니라 수집 범위·수집량 변화일 가능성이 크므로, 수집 완전성과 월별 노출량을 확인하기 전에는 시계열 추세로 해석하면 안 된다.
- 네일·시술·주문제작 케이크 등 서비스 홍보 표식은 707건이다. 이는 IP 확장성 신호가 될 수 있지만 소비자 인기와 같은 지표로 합치면 특정 판매계정의 반복 게시가 결과를 왜곡할 수 있다.
- 좋아요는 중앙값 450, 평균 2,855.6, 최대 222,028로 우측 꼬리가 매우 길다. 댓글도 중앙값 5, 평균 118.1, 최대 27,789다. 반응 분석은 평균보다 중앙값·로그변환·상하위 절삭을 권장한다.

## 2. 실제 분석에 사용한 정제 기준

인기 요소를 과대해석하지 않기 위해 다음 기준의 고정밀 하위표본을 사용했다.

1. 본문이 존재하고 2020년 이후인 게시물
2. 정규화 본문 완전중복은 최초 1건만 유지
3. 치이카와·치카와·먼작귀·Chiikawa·ちいかわ 중 하나를 명시한 게시물
4. 네일·시술·타투·주문제작 케이크 등 서비스 홍보 문구는 인기요소 분석에서 분리

최종 분석 표본은 **7,795건**이다. 이 기준은 정밀도를 높이는 대신 캐릭터명만 쓴 게시물이나 이미지에만 치이카와가 있는 게시물을 제외할 수 있으므로, 전체표본과 함께 민감도 분석을 해야 한다.

## 3. 형태소 기반 핵심 키워드

## 4. 동시출현 및 연관규칙

같은 게시물에 함께 나온 키워드 쌍을 계산했다. 지지도는 전체 정제 표본 중 두 단 어가 함께 나온 비율이고, 향상도는 독립적으로 등장할 때보다 함께 나올 가능성이 얼마나 높은지 나타낸다.

향상도가 높아도 동시출현 건수가 작으면 불안정하다. 보고서 본문에서는 최소 동시출현 15건을 적용했고, 최종 의사결정용으로는 30건 이상 또는 부트스트랩 신뢰구간을 권장한다.

## 5. 프로젝트 평가영역별 결과

| 평가영역 | 포함 게시물 | 언급률 |
|---|---:|---:|
| 굿즈·소장 | 2,875 | 36.88% |
| 시각적 매력 | 2,091 | 26.82% |
| 구매·희소성 | 1,742 | 22.35% |
| 스토리·세계관 | 1,075 | 13.79% |
| 오프라인 경험 | 1,058 | 13.57% |
| 창작·커스터마이징 | 771 | 9.89% |
| 정서·공감 | 549 | 7.04% |
| 콜라보·확산 | 517 | 6.63% |

이 분류는 다중 라벨이므로 비율 합계가 100%를 넘을 수 있다. 영역 간 동시출현은 인과관계가 아니라 같은 게시물에서 함께 언급된 구조다.

동시출현 건수는 굿즈·소장–구매·희소성 1,246건, 시각적 매력–굿즈·소장 1,107건, 굿즈·소장–오프라인 경험 749건, 구매·희소성–오프라인 경험 668건이다. 상품 관심이 구매 및 현장 경험과 함께 묶이는 구조는 차기 IP의 상품화·오프라인 확장성을 평가할 근거가 된다. 다만 공급자 홍보를 분리한 뒤에도 유지되는지 추가 검증해야 한다.

## 6. 차기 국내 창작자 IP 선정 기준으로의 전환

| 선정 기준 | 치이카와 데이터에서 볼 지표 | 후보 IP 평가 방식 |
|---|---|---|
| 시각적 매력 | 귀여움·표정·디자인 언급률 | 전체 게시물 대비 매력표현 DF, 반응 중앙값 |
| 정서적 연결 | 정서·공감과 스토리의 동시언급 | 두 영역 지지도·향상도, 댓글의 공감 표현 |
| 상품화 잠재력 | 굿즈·소장과 구매·희소성 연결 | 굿즈 언급률, 구매 관련 향상도, 광고 제외 민감도 |
| 콘텐츠 확장성 | 스토리·세계관·캐릭터 관계 | 서사 관련 언급률, 캐릭터별 차별적 키워드 |
| 오프라인 확장성 | 팝업·매장·카페·전시 언급 | 오프라인 경험 언급률과 기간별 지속성 |
| 협업 확산성 | 콜라보·브랜드·창작 표현 | 협업 언급률, 파트너 유형 다양성, 반복계정 편향 점검 |
| 관심 지속성 | 월별 게시물·키워드 변화 | 이벤트 피크 제거 후 기준선, 3·6개월 잔존율 |

후보 IP 비교 시 모든 IP에 동일한 기간·수집어·정제 규칙·최소 표본수를 적용해야 한다. 치이카와 하나의 절대 빈도를 국내 후보에 그대로 대입하면 플랫폼 규모와 검색어 차이를 IP 매력으로 오인할 수 있다.

## 7. 권장 후속 분석

1. `media_type_id`의 코드북을 확인해 이미지·영상·릴스별 반응을 비교한다.
2. 계정 ID가 없으므로 현재는 반복 게시자를 통제할 수 없다. 원천 데이터에서 `owner_id` 또는 `username`을 추가해 계정별 1일/1주 상한 또는 가중치를 적용한다.
3. 좋아요 결측 13.71%의 발생 조건을 연도·미디어 유형별로 확인한 뒤 반응 분석의 포함 기준을 확정한다.
4. 광고·판매·팬 콘텐츠·공식계정을 분류해 인기 요인과 공급자 홍보를 분리한다.
5. 월별 키워드 언급률을 계산하고 팝업·출시 이벤트 전후의 단기 피크와 장기 기준선을 구분한다.
6. 국내 창작자 후보 IP에도 같은 파이프라인을 적용하고 부트스트랩 신뢰구간과 표본 크기 보정을 포함한다.

## 해석 한계

- 이 데이터는 인스타그램 게시물이며 전체 소비자 인식을 대표하지 않는다.
- 빈도와 동시출현은 인과관계 또는 실제 구매전환을 의미하지 않는다.
- 계정 정보, 노출수, 팔로워 수가 없어 반응 수를 공정하게 표준화할 수 없다.
- 명시적 브랜드 언급 표본은 정밀도 중심 설계이며 이미지 기반 언급을 놓칠 수 있다.
