# A~H 댓글 내용 분류 기준 v2

기준 버전 `ah-context-v2`. 판정 모델은 Grok 4.7. 방식은 댓글 본문을 읽는 문맥 판정이다. 키워드는 재검토 후보를 찾는 데만 쓰고, 최종 판정을 대신하지 않는다. 사람 검수는 하지 않았다. 이 기준은 표본 5,000건에만 적용한다. 나머지 62,891건은 분류하지 않는다.

원본 `01_댓글판정.csv`와 `경계검토/`의 200건 재검토는 덮어쓰지 않는다. 수정본은 이 폴더에만 둔다.

영상의 `A_우선포함`과 댓글 유형 A는 다른 분류다. 주유형은 댓글마다 A~H 중 하나이고, 본문의 핵심 목적이다. 보조유형은 본문에 다른 목적이 명시된 때만 적고, 주유형과 같은 코드는 적지 않는다. 여러 개면 `|`로 잇는다. 제목으로 본문에 없는 목적을 만들어 주유형을 정하지 않는다. 제목을 봐야 해석이 달라질 때만 제목 보조를 `예`로 두고 제안 유형을 따로 적는다.

## 유지하는 유형 정의

| 코드 | 이름 | 기준 |
|---|---|---|
| A | 작품·캐릭터 감상·장면 공유 | 작품·캐릭터·관계·세계관·목소리·장면의 감상과 평가. 부정 평가, 작품 더빙, 노래, 세계관 포함 |
| B | 개인 상품 관심·소비·소유·사용 | 작성자의 상품 관심, 구매·획득·소장·사용, 의향, 구매처·가격·판매 가능 여부 질문 |
| C | 팬 창작·꾸미기·제작물 공유 | 팬아트·만들기·더빙·꾸미기 등 제작물의 공유·평가·요청 |
| D | 상품·거래·협찬·이벤트 안내 | 판매·교환 상대 모집, 공동구매, 협찬, 광고, 이벤트 안내·응모 |
| E | 다른 인물·대상·팬덤 관련 | 사람 자체의 매력·성격·외모·응원, 다른 작품·다른 팬덤이 중심 |
| F | 콘텐츠 정보·번역·독자 교류 | 회차·출처·업로드·번역, 시청 안내, 감사·인사, 콘텐츠 제공 요청 |
| G | 본문만으로 목적 판단 어려움 | 대상이나 요청 내용이 본문에 없어 목적을 정할 수 없음 |
| H | 비한국어 본문 | 한국어 문장으로 보기 어려운 외국어 중심 본문 |

장면 속 “갖고 싶다”와 캐릭터에게 하는 말은 A다. 작품 더빙·성우 목소리 평가는 A다. 이름·웃음·이모지만 있으면 G다. 자모나 영문을 의미 없이 두드린 본문은 G다. 외국어 단어가 조금 섞인 한국어 문장은 H가 아니다.

## BD. 개인 상품 관심과 이벤트·거래

문구의 위치, 본문 길이, ‘이벤트’라는 단어의 유무만으로 정하지 않는다. 개인 질문과 거래 상대 모집은 문장 전체로 구분한다.

| ID | 본문 | 판정 |
|---|---|---|
| BD-Q | 구매처, 가격, 살 수 있는지, 팔 생각이 있는지, 교환이 되는지를 작성자가 묻는다 | B |
| BD-R | 판매·교환 상대를 모집하거나, 이벤트 안내·응모가 그 댓글의 핵심 행위다 | D |
| BD-BD | 상품 평가나 구매·미구매·소장이 그 자체로 성립하고, 이벤트 참여도 같이 적혀 있다 | B, 보조 D |
| BD-DB | 응모·당첨·이벤트 감사가 핵심이고, 원하는 상품은 그 대상을 설명하는 말이다 | D, 보조 B |
| BD-HOLD | 개인 소비와 응모·모집이 둘 다 명시되어 있고, 어느 쪽이 핵심인지 본문으로 갈라지지 않는다 | 주유형은 기존 값을 유지하고 사용자 확인으로 남긴다 |

- 순번 1604 `판매하실 생각 있으신가요`는 판매 가능 여부를 묻는 개인 질문이라 B다.
- 순번 2776 `맞구 가능 한가요`는 교환이 되는지를 묻는 질문이라 B다. `치이카와 너무 기여워용`은 보조 A다.
- 순번 1711 `누가 교환쥼 해주세용`은 교환 상대를 구하는 모집이라 D다.
- 순번 1049 `(이벤트) 우사기!!! ... 뽑고 싶어요`는 응모가 핵심이고 원하는 상품을 적었으므로 D, 보조 B다.
- 순번 2651은 이벤트에 감사하고 하치와레를 원한다고 하며, 히퍼를 못 산 경험은 보조 B다. D, 보조 B다.
- 순번 1269는 상품 평가와 갖고 싶다는 말이 그 자체로 성립하고 이벤트 참여가 같이 있으므로 B, 보조 D다.
- 순번 2170도 미니소·태닝키티 평가가 성립하고 끝의 참여 문장이 추가되므로 B, 보조 D다. `금손이시네요`는 제작물인지 사람인지 본문이 특정하지 않아 보조 C나 E로 올리지 않는다.

## CEG. 제작 기술과 사람 칭찬

`금손이다`와 `금손이세요`를 말투 차이만으로 나누지 않는다. 제작 영상이라는 이유만으로 제목을 주유형 C의 근거로 쓰지 않는다. 제작 기술을 사람에게 말했다는 이유만으로 보조 E를 붙이지 않는다.

| ID | 본문 | 판정 |
|---|---|---|
| CEG-C | 그림, 만들기, 꾸미기, 손재주, 도안, 뜨개처럼 제작물이나 제작 기술이 본문에 특정된다 | C |
| CEG-E | 사람 자체의 매력, 성격, 외모, 응원이 중심이다 | E |
| CEG-G | `금손`, `잘한다`만 있고 무엇을 평가하는지 본문으로 특정할 수 없다 | G. 제목이 제작을 드러내면 제목 제안만 C |
| CEG-NOE | 기존 보조 E가 기술을 사람에게 말했다는 이유뿐이면 보조 E를 뺀다 | 주유형 C 유지 |

- 순번 246 `손재주`와 방에 꾸밀 공간을 만들고 싶다는 말은 C다.
- 순번 4112 `손재주가 좋으시네요`는 제작 기술이 본문에 있으므로 C다.
- 순번 1708은 잘 그린다는 말과 도안 요청이 있으므로 C를 유지하고, 사람에게 말했다는 이유의 보조 E는 뺀다.
- 순번 437 `오늘도 너무 금손이세요`와 순번 2329 `금손이다`, 순번 3225 `개잘하신다`는 평가 대상이 본문에 없다. 주유형은 G다. 437과 3225는 제목이 제작·성대모사라 제목 제안만 C다. 2329의 제목은 쿠지라 제목으로 C를 제안하지 않는다.

## CFG. 요청 댓글

만들기 동사가 없다는 이유만으로 F로 두지 않는다. 제목으로만 요청 대상이 드러나면 주유형과 별도로 제목 제안을 적는다.

| ID | 본문 | 판정 |
|---|---|---|
| CFG-C | 팬 창작, 제작, 꾸미기를 해 달라는 요청이 본문에 있다 | C |
| CFG-F | 업로드, 회차, 번역, 영상 제공을 해 달라는 요청이 본문에 있다 | F |
| CFG-G | 무엇을 해 달라는지 본문만으로 알 수 없다 | G |

- 순번 4409 `레몬탱 해주세용`은 만들어 달라는 말도, 올려 달라는 말도 없다. 주유형은 G다. 제목은 댄스 영상이라 요청 종류를 확정하지 않으므로 제목 제안으로 C나 F를 만들지 않는다.

## 본문에 작품 대상이 없는 경우

순번 3960 `제 어머니랑 생일이 똑같아요`는 작품·상품·제작 요청이 본문에 없다. 주유형은 G다. 제목이 치이카와 생일이므로 제목 제안만 A다. 이 사례는 BD·CEG·CFG 문구로 연 것이 아니라, 제목으로 본문에 없는 목적을 만들지 않는다는 기존 규칙을 다시 확인한 것이다.

기준만으로 핵심이 갈리지 않으면 추측하지 않고 사용자 확인으로 남긴다. `사용자_확인`과 `사용자_의견`이 빈칸인 것은 동의가 아니다.
