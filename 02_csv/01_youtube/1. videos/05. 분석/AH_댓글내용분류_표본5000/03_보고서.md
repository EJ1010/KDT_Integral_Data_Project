# A~H 댓글 내용 분류 — 표본 5,000건

이 수치는 한국어 중심·혼합 67,891건에서 시드 42로 뽑은 **표본 5,000건**의 분포다. 전체 67,891건의 확정 건수가 아니다. 사람 정답과 비교하지 않았으므로 정확도는 적지 않는다.

판정은 Grok 4.7이 댓글 원문을 읽어 한 건씩 정했다. 프롬프트 버전은 `ah-context-v1`이다. 주유형은 본문만으로 정했고, 제목으로 달라지는 해석은 보조 칸에만 남겼다.

## 입력과 완료

| 항목 | 건수 |
|---|---:|
| 기준 집단 | 67,891 |
| 표본 | 5,000 |
| 판정 완료 | 5,000 |
| 실패 | 0 |
| 미처리 | 0 |
| 표본 밖 남은 댓글 | 62,891 |

출력 고유 `comment_id` 5,000개가 표본 ID와 같고, 중복과 표본 밖 ID는 없다. 주유형은 댓글마다 하나이고 합계는 5,000이다. 댓글 원문과 `post_id` 연결은 입력 추출과 같다.

## 경계와 기준 보완

첫 100건에서 고정한 경계는 그대로 두었다. 5,000건을 합친 뒤 한 가지를 분명히 했다. 자모나 영문을 의미 없이 두드린 본문은 외국어 문장이 아니므로 H가 아니라 G다. 해당 댓글은 순번 4813 한 건이고, H에서 G로 바꿨다.

- 작품 해석이 중심이고 상품 언급이 따라오면 주유형 A, 보조 B다. 순번 201은 굿즈 로고로 세이렌 결말을 읽는다.
- 갖고 싶거나 못 뽑았거나 직접 쓰는 말이 중심이면 주유형 B다. 순번 4는 갖고 싶지만 뽑히지 않은 미획득이고, 순번 9는 실물을 닦는 사용이다. 캐릭터 감상은 보조 A로 남겼다.
- 본인이 갖고 싶다고 하면서 이벤트에 응모하면, 갖고 싶다는 말이 중심일 때 B(보조 D), 응모 문구가 본문일 때 D(보조 B)다. 순번 31은 못 산 의향이 앞이고, 순번 5는 나눔 응모가 본문이다.
- 다른 팬덤의 포토카드를 꾸미자는 말은 C이면서 대상이 치이카와 창작이 아니면 보조 E다. 순번 723이 그 경우다.
- 업로더를 응원하면서 영상을 잘 봤다고 하면 사람이 중심일 때 E(보조 F), 시청·요청이 중심일 때 F(보조 E)다.
- 대상이 없는 “귀여워”는 G다. G 422건 중 404건은 제목을 보면 해석이 달라져 제안 유형을 따로 적었다. 제안은 A 275, B 83, C 33, E 7, F 5, D 1이다. 주유형은 G로 두었다.

제목 보조 해석을 남긴 댓글은 전체 574건이다. 추가 검토 표시는 1,039건이다. 이 표시는 판정할 때 본문이 짧거나 두 번째로 읽힐 여지가 있어 달아 둔 것이고, 사람 검수 결과가 아니다. G 422건 중 401건이 여기 포함된다.

## H 재분류

H는 3건이다. 실패가 아니다.

- 순번 523, 4979: 기존 판정은 한국어 중심이다. 본문은 일본어 가사를 한글로 적은 것이고 한국어 문장이 없어 H로 뒀다.
- 순번 1738: 기존 판정은 혼합_한국어 중심이다. 내용을 말하는 문장은 일본어이고 한국어는 “귀여워”뿐이라 H로 뒀다. 검토 표시를 남겼다.
- 혼합 23건 가운데 H로 옮긴 것은 1738 한 건이다. 나머지 혼합은 한국어 문장 안에 외국어가 섞인 것으로 보고 A–G에 남겼다.

근거를 비운 댓글은 2건(순번 3097, 4813)이다. 글자가 깨졌거나 발췌할 구간이 없어 문구를 만들지 않았다.

## 시간

로컬 시각 기준이다. 여러 묶음을 동시에 읽었고, 시간은 벽시계 경과다.

- 입력 확인·표본 추출: 1분 3초 (16:19:16–16:20:19)
- 5,000건 문맥 분류: 28분 52초 (16:20:48–16:49:40)
- 재처리·검증·집계: 3분 40초 (16:49:40–16:53:20)
- 전체: 34분 4초

완료 5,000건 기준 분당 173.2건이다. 같은 모델, 같은 프롬프트, 같은 병렬 읽기가 유지되면 남은 62,891건은 약 6시간 3분이다. 기준을 바꾸거나 중단된 묶음을 다시 읽으면 더 길어진다. 이번 28분 52초 안에는 2501–2900번을 한 번 다시 읽은 시간이 이미 들어 있다.
