# 표본 5,000건 실행 기록

## 입력

- 댓글: `03. 분석용테이블/youtube_total_cleaning_classified_A_comments.csv` (고유 댓글 90,921건)
- 언어 판정: `05. 분석/A_키워드/01_댓글판정.csv`의 `language_class`
- 기준 집단 함수: `A_상품소비_1차분류/classify_A_goods_screen_v1.py`의 `population()`
- 재계산 결과: 한국어 중심 67,546건 + 혼합_한국어 중심 427건, 광고·스팸 제외 후 **67,891건**
- 고유 `comment_id` 중복 0, 결측 0, 댓글의 `account_id`와 영상 채널 불일치 0, 제목 결측 0
- `account_id`는 영상 채널 ID다. 댓글 작성자 식별자는 넣지 않았다.
- 요청한 67,891건과 실제 대상이 같아서 건수를 맞추지 않았다.
- 호감·소비 후보로 범위를 줄이지 않았고, 이전 분석에 들어간 댓글도 빼지 않았다.
- 원본 댓글과 기존 분석 파일은 수정하지 않았다.

## 표본

- 67,891건을 `comment_id` 오름차순으로 정렬한 뒤 `DataFrame.sample(n=5000, random_state=42)`로 단순 무작위 비복원 추출
- 추출 뒤 다시 `comment_id`로 정렬하고 순번 1–5000을 부여
- 길이, 좋아요, 영상, 유형으로 골라내지 않음
- 결과: 고유 댓글 5,000건, 영상 1,681개, 채널 716개
- 기존 언어 판정: 한국어 중심 4,977건, 혼합_한국어 중심 23건
- 빈 본문 0건
- ID 목록: `00_표본ID.csv`
- 판정에 붙인 원문 추출: `_입력5000.csv` (댓글 원문은 `comment_description` 그대로)

## 판정

- 모델: Grok 4.7
- 방식: 댓글 원문을 한 건씩 읽는 LLM 문맥 판정. 키워드 규칙으로 최종 라벨을 만들지 않음
- 프롬프트 버전: `ah-context-v1` (`00_기준.md`)
- 별도 유료 API나 외부 분류 서비스는 연결하지 않음
- 순번 1–100을 먼저 읽고 경계를 고정한 뒤, 그 100건을 표본에 포함한 채 5,000건까지 진행
- 묶음 판정은 `_j_*.jsonl`에 저장했다. 같은 순번이 두 파일에 겹치지 않는다.
- 2501–2900번은 한 묶음이 판정 파일 없이 중단되어, 2501–2700과 2701–2900으로 나눠 다시 읽었다. 그 재독은 아래 문맥 분류 경과 시간 안에 들어 있다.

## 시각

시각은 이 PC의 로컬 시각이다. 동시에 여러 묶음을 읽었으므로, 아래는 벽시계 시간이고 묶음별 시간을 더한 값이 아니다.

문맥 분류 28분 52초 기준 처리량은 완료 5,000건으로 **분당 173.2건**이다.

## 검증에서 고친 것

- 순번 16 근거를 원문 철자 `치이카와 였어욬`로 맞췄다.
- 순번 3177, 3257 근거를 원문 구간으로 맞췄다.
- 순번 4813은 자모·영문 난타라 외국어 문장이 아니다. H에서 G로 바꿨고, 제목 제안은 A로 남겼다. 같은 형태의 다른 H는 없었다.
- 순번 3097, 4813은 본문이 깨져 있거나 발췌할 구간이 없어 근거를 비웠다. 문구를 만들지 않았다.

실패 0건, 미처리 0건. G 422건과 H 3건은 완료된 판정이다.

## 재개 상태

표본 5,000건에서 멈춘다. 남은 고유 댓글은 67,891 − 5,000 = **62,891건**이다. 같은 모델·같은 병렬 읽기·같은 프롬프트가 유지될 때의 조건부 추정은 62,891 / 173.2 ≈ **363분(약 6시간 3분)**이다. 검토를 늘리거나 묶음이 다시 중단되면 더 길어진다. 사용자 답변 전에는 나머지 댓글을 읽지 않는다.
