# 수집 댓글 기준 한국어 반응 우세 영상

규칙 버전: `b-kr-comment-v1`

이 결과는 B 영상 가운데 수집된 댓글에서 한국어 반응이 우세한 영상을 고른 것이다. 시청자 국가나 한국인 비율을 추정하지 않았고, 제작자가 한국 이용자를 겨냥했다는 뜻도 아니다.

## 사용한 자료

- 영상: `youtube_total_cleaning_classified.csv`에서 `final_class = B_관련있음_한국어대상검토`
- 댓글 본문: `2. comments/raw/youtube_comments_2022.csv` ~ `2026.csv`
- 수집 상태: `2. comments/raw/youtube_comment_status_2022.csv` ~ `2026.csv`
- 연결: 댓글 `video_id` = 영상 `post_id`. 앞뒤 공백과 URL 형식은 없었다.

댓글 파일에는 `comment_id`, `video_id`, `text`, `published_at`, `updated_at`, `like_count`, `reply_count`, `parent_id`가 있다. 작성자 ID는 없다. `parent_id`는 16만 938행 모두 비어 있다.

## 수집 범위

| 항목 | 확인 결과 |
| --- | --- |
| 정렬(인기순·최신순) | 확인 불가. 결과 파일에 정렬 값이 없고, API 초안은 주석 처리되어 있다. |
| 수집 상한 | 상태 파일의 최댓값은 100이다. `capped` 177편은 `next_token`이 남아 100개에서 중단됐다. |
| 페이지 수 | 확인 불가. 페이지 횟수 열이 없다. |
| 대댓글 본문 | 없음. `reply_count`는 최상위 댓글에 달린 답글 수만 기록한다. |
| 작성자 | 없음. 작성자 이름·프로필로 언어나 국적을 보지 않았다. |

## 계산식

- 유효 댓글 = 빈 댓글과 광고·스팸을 뺀 댓글
- 언어 판별 가능 댓글 = 한국어 중심 + 혼합_한국어 중심 + 외국어 중심
- 한국어 댓글 비율 = (한국어 중심 + 혼합_한국어 중심) / 언어 판별 가능 댓글
- 언어 판별 가능 비율 = 언어 판별 가능 댓글 / 유효 댓글
- 분모가 0이면 비율을 만들지 않는다.

`comment_id` 중복은 0건이었다. 같은 문장을 다른 행에 썼다는 이유만으로 지우지 않았다. 작성자 비율과 대댓글 집중 검증은 필드가 없어 수행하지 못했다.

## 운영 기준

초기 기준을 유지했다. 포함 수를 늘리려고 기준을 낮추지 않았다.

- `B-KR_포함후보`: 판별 가능 댓글 20개 이상, 한국어 댓글 비율 70% 이상, 판별 가능 비율 50% 이상
- `B-KR_추가검토`: 비율 50% 이상 70% 미만이거나, 70% 이상이어도 댓글 수 또는 판별 가능 비율이 기준 미만
- `B-KR_기준미충족`: 판별 가능 댓글 20개 이상, 비율 50% 미만, 판별 가능 비율 50% 이상
- `B-KR_근거부족`: 매칭 댓글이 없거나 판별 가능 댓글이 없거나, 위 구간으로 판단하기 어려움

기준미충족은 한국인이 보지 않은 영상이라는 뜻이 아니다.

## 임계값 비교

판별 가능 비율 50% 이상을 유지하고, 최소 댓글 수와 한국어 비율만 바꿨다.

| 최소 댓글 | 비율 | 해당 영상 | 운영 기준 2편과의 차이 |
| ---: | ---: | ---: | --- |
| 10 | 60% | 3 | 1편 추가 |
| 10 | 70% | 3 | 1편 추가 |
| 10·20·30 | 80% | 2 | 같음 |
| 20·30 | 60% | 2 | 같음 |
| 20·30 | 70% | 2 | 같음 |

20개·70%를 10개로 낮춰도 1편만 늘어난다. 60%로 낮춰도 20개 이상에서는 늘지 않는다. 운영 기준을 유지한다.

## 표본 검수

언어 분류 출력에서 외국어 중심, 한국어 중심, 혼합, 판단 불가, 빈 댓글을 읽어 보았다. 일본어 문장은 외국어 중심, `귀엽네요`, `편집봐`처럼 의미가 있는 한국어는 한국어 중심으로 갈렸다. 이모지만 있는 댓글은 판단 불가다.

수정한 오류는 하나다. `さすが사장님`처럼 일본어 문장에 한글 단어가 붙은 댓글이 한국어 중심으로 들어갔다. 다른 언어 문자가 함께 있으면 혼합_한국어 중심으로 바꿨다. 혼합도 한국어 반응 분자에 포함되므로 포함후보 2편은 그대로다.

남은 경계는 한글로 적은 일본어(`카와이데스네`)와 `우나나 야하하` 같은 리듬 표현이다. 둘 다 한국어 중심에 남을 수 있다. 포함후보 두 편의 비율을 70% 아래로 내릴 만큼 많지는 않았다.

제목이 일본어·영어인 B 영상은 댓글도 외국어 중심인 경우가 많다. 기준미충족 700편은 그 경우다. 제목이 외국어라는 사실과 댓글의 한국어 반응은 따로 판정했다.

## 검증

- B 입력 3,249편과 판정 파일 3,249편의 `post_id`가 같다.
- 포함후보 `post_id` 2개는 중복이 없고 입력 B 안에 있다.
- 댓글은 영상 집계 후 영상 행에 한 번만 붙였다. 영상 수가 댓글 수만큼 늘지 않았다.
- 원본 분류 CSV와 댓글 CSV는 수정하지 않았다.

## 한계

- 정렬 순서와 페이지 수는 확인 불가다. 상한이 있는 177편은 수집된 100개 안의 비율이다.
- 대댓글 본문과 작성자 ID가 없어 한 사람의 반복 댓글, 대댓글 몰림, 작성자 기준 비율을 보지 못했다.
- 댓글이 치이카와에 대한 반응인지는 이번 언어 비율에 넣지 않았다. 인기 요소 분석은 다음 단계다.
- A 집단과 이번 B-KR 포함후보는 출처가 다르다. 포함후보를 A에 합치지 않는다.
