# 소비·활용 기준서

실행 시각 `2026-11-03T14:54:12+09:00`. 입력은 `normalized/x_posts.csv`의 고유 `post_id` 5,000건이다. 키워드 표는 언급 횟수로 쓰지 않았다. 기존 텍스트 분석·이미지 검토의 라벨은 정답으로 쓰지 않았다.

판단은 세 층이다.

- `rule_screen`: 상품·소비 어휘가 없어 근거 행을 만들지 않음. 게시물마다 읽은 것이 아니다.
- `rule_calibrated`: 구절 규칙. 1차 작성자 행동 묶음을 읽고 오탐을 줄인 뒤의 규칙이다. 그 묶음의 게시물 ID를 전부 `model_context`로 남기지는 않았다.
- `model_context`: `working/model_read_ids.txt`의 20건. 원문 또는 사진까지 보고 규칙을 고치거나 그대로 둔 글이다. 별도의 사람 검토자는 없다.

사진 확인은 데스크톱 Google Chrome에서 연 5건만 `예`다. 보지 않은 이미지는 확인으로 표시하지 않는다.

## 게시 맥락

한 글에 여러 맥락이 있을 수 있다. `primary_context`는 하나만 고른다. 우선순위는 작성자 경험, 구매 고민, 작성자 희망·시도, 개인 거래, 판매·홍보, 정보 공유, 언급이다.

| 값 | 기준 |
|---|---|
| 작성자 | 본인이 사거나, 갖고 싶거나, 쓰거나, 다녀왔다고 한 말 |
| 판매·홍보 | 재고·예약·입고·구매 안내. 판매 문안의 ‘달아서 쓰세요’는 작성자 사용이 아님 |
| 개인 거래 | 양도·교환·나눔 문안. `삽니다`는 산다는 뜻이라 판매로 보지 않음 |
| 정보 공유 | 일정·장소·출시 정보를 전하는 말 |
| 인용된 타인 | 따옴표 안 다른 사람의 희망·착용 |
| 다른 사람 관찰 | ‘달고 다니는 사람들’처럼 타인을 본 말 |

## 상품 형태와 다른 축

형태, 기능, 획득 방식, 디지털 콘텐츠, 장소는 한 칸에 섞지 않는다. 가챠·공구·쿠지는 형태가 아니라 획득 또는 판매 채널이다. 인형뽑기는 가챠와 따로 둔다.

이야기 속 옷·음식(오징어 옷, 푸딩을 먹는 장면)은 상품이 아니다. `피규어샵`, `굿즈샵`, `원피규어`는 가게 이름이라 피규어 상품으로 세지 않는다. 상품명의 ‘컬렉션’은 모으기 행동이 아니다. 판매 글의 ‘미개봉’은 상품 상태이지, 아까워서 보관한다는 뜻이 아니다.

| 형태 | 메모 |
|---|---|
| 봉제 인형 | 인형. 마스코트와 구분 |
| 마스코트(소형 봉제) | 작은 봉제. 키링 고리가 있으면 기능 축에 부착을 따로 적음 |
| 키링·스트랩 | 고리·스트랩이 본문 또는 확인한 사진에 있을 때 |
| 피규어 | 피규어. 가게 이름 제외 |
| 아크릴 제품 | |
| 스티커·씰 | |
| 카드·트레카 | 이야기에서 캐릭터가 카드를 원하는 장면은 제외 |
| 뱃지·마그넷 | `자석처럼`은 제외 |
| 휴대폰 부착 소품 | |
| 문구 | 수정테이프, 북마크, 스탬프, 띠부씰, 여권케이스 포함 |
| 파우치·수납 | 본문에 파우치·수납이 있을 때. 사진만으로 파우치라고 확정하지 않음 |
| 식기·컵 | |
| 생활섬유 | |
| 의류·패션소품 | 잠옷·티셔츠·팔찌. 인형의 파자마 버전, 파자마파티즈는 제외 |
| 생활용품 | 샤워볼, 램프, 팬케이크 메이커. 샤워볼+피규어는 생활용품 하나 |
| 식품·음료 | 맨 초코, 쿠키키링, 이야기 속 음식은 제외 |
| 만화·서적 | |
| 이모티콘 | 출시 안내만인 경우는 사용이 아님 |
| 애니메이션, 영화 | 구매 동사를 이 형태에 붙이지 않음 |
| 게임 | 사진·영상으로 게임 화면이 확인된 경우. 실물 뽑기와 구분 |
| 놀이 세트 | 집·피규어로 가지고 논다고 확인된 경우. 식품이 아님 |
| 봉제 소품 | 사진에서 봉제는 보이나 인형·파우치·담요로 가르지 못한 경우 |
| 팝업·전시, 카페·매장, 콜라보·행사 | 장소·행사. 같은 구절에 물건이 있으면 구매 동사는 물건에만 붙임 |
| 형태 불특정 굿즈 | 굿즈라고만 한 경우 |
| 형태 불명확 | 샀다·뽑았다만 있고 물건 이름이 없는 경우 |

기능은 이름에서 온 기능(`function_from_name`)과 작성자가 말한 사용(`use_mode`)을 분리한다. 인형 키링은 형태와 부착을 같이 둘 수 있다.

## 소비·활용 방식

본문에 그 방식이 있을 때만 부여한다. 희망과 경험을 `temporal`로 가른다. ‘달고 싶다’는 희망, ‘달고 다닌다’는 경험이다. 안 뜯었다·아까워서 못 쓴다는 말은 불만이 아니다. 작성자가 이유를 말하면 그 이유를 적고, 없으면 보관으로만 둔다.

사용한 방식 값은 다음과 같다. 후보 목록에 있어도 근거가 없는 항목은 표에 없다.

- 가방·휴대전화 등에 달고 다니기
- 책상·선반 등에 전시하기
- 보관·소장하고 바라보기
- 문구·생활용품으로 사용하기는 본문이 그 사용을 말할 때만. 상품이 문구라는 이유만으로 넣지 않음
- 꾸미기·제작·재해석에 활용하기
- 특정 캐릭터의 여러 상품·버전 모으기
- 선물하거나 다른 사람과 함께 즐기기
- 이모티콘·콘텐츠로 감정을 표현하거나 소통하기
- 시청·관람·방문하기
- 기타: 장난감으로 가지고 놀기
- 방식 불명확

여러 캐릭터를 조합해 세트를 완성한다는 말은, 그 문장이 있을 때만 따로 적는다. 사진에 여러 개가 같이 있다는 사실만으로 세트 완성 동기를 만들지 않는다.

## 행동 상태

주체(`speaker`), 대상(상품·캐릭터), 상태(`behavior_status`)를 한 행에 둔다. 한 글의 여러 행동은 행을 나눈다. 모든 상품과 모든 행동을 곱하지 않는다.

| 행동 | 상태 예 |
|---|---|
| 상품·콘텐츠 언급 | 언급. 구매·선호가 아님 |
| 구매·소장·사용 희망 | 희망 |
| 구매 고민 | 고민 |
| 구매·획득 경험 | 완료·경험 |
| 실제 소유·사용·수집 경험 | 완료·경험 |
| 시청·방문 경험 / 희망 | 장소·콘텐츠 |
| 구매 시도·실패·포기 | 시도(결제·예약, 수령 미확인) 또는 미수행·포기 |
| 판매·교환·양도 | 거래 화자 |
| 판단 불가 | 꿈에서 샀다 등 |

획득은 직접 구매, 선물, 교환, 나눔, 공동구매, 가챠·뽑기, 인형뽑기, 게임 내 획득, 불명확로 구분한다. `결국 안 샀다`는 미수행이다. `몇 개 안 샀다`는 적게 산 경험이다. `구매했을`처럼 가정은 완료가 아니다. 장바구니는 담거나 넣었다는 말이 있을 때만 시도로 본다.

## 좋아하는 이유

연결어(`아서/어서/해서/…/때문에/니까/길래`)의 오른쪽 행동에만 붙인다. `에서`, `것같아서`는 이유가 아니다. 이유 단어는 연결어 왼쪽 끝 18자 안에서만 본다. 막연한 귀엽다·좋다는 포괄 호감이고, 디자인 특징으로 올리지 않는다. 발견·반가움(`있길래`, `반가워서`)은 상품 특징 선호가 아니다. 미수행에는 호감 이유를 붙이지 않는다. ‘한정’만으로 희소성 이유를 만들지 않는다. 가격이 옆에 있어도 연결어가 없으면 가격을 이유로 적지 않는다.

| 이유 | 예 |
|---|---|
| 특정 표정·의상·포즈·장면 | 표정이 취향 |
| 촉감·품질·기능 등 상품 구현 | 고리가 별 모양 |
| 포괄 호감(세부 특징 없음) | 귀여워서 샀다. 무엇이 귀여운지는 없음 |
| 기타: 발견·반가움·눈에 띔 | 있길래, 반가워서 |
| 기타: 기분·상황 | 우울해서 샀다 |
| 기타: 다른 대상과 닮아 보임 | 다른 대상과 닮아서 |
| 이유 미언급·판단 불가 | 샀다, 갖고 싶다만 있는 경우 |

바라봄·위로, 가까이 두기, 실용, 모으기, 아까워서 간직함은 그 단어가 이유 자리에 있을 때만 쓴다. 이번 명시 이유 10건 안에는 그 항목으로 확정된 행이 없다. 힐링은 표정 구매 글에서 바라는 결과로 본문에 있으나, 연결어가 표정 쪽에 있어 이유 칸은 표정으로 두었다.

## 연결 수준

1. 단순 공존: 같은 글에 있으나 그 구절이 그 상품의 행동이라고 단정하지 못함. 상품 형태가 하나일 때만 다른 구절과 연결하고, 이미 명시적 이유인 행은 단순 공존으로 내리지 않음.
2. 문맥상 연결: 무엇을 샀거나 어떻게 쓰는지 문장으로 확인.
3. 명시적 선호·이유: 그 상품이나 그 방식의 좋은 점을 연결어로 말함.
4. 연결 불명확: 대상이나 뜻을 정하기 어려움.
5. 이용 방식 없음: 이름만 있음.

## 사진

직접 첨부와 인용·답글·미리보기를 구분한다. 상품 사진만으로 구매·사용을 확정하지 않는다. 본문이 구매를 말하고 사진이 물건을 보여 주면 형태를 고칠 수 있다. 사용 방식은 본문이 말할 때만 추가한다.

확인한 5건은 `working/image_checks.csv`에 있다. 형태가 불명확한 작성자 글 중 나머지 27건은 열지 않았다.
