# 캐릭터 사전과 분류 기준

- 규칙 버전: `2026-11-03.reaction.v3`
- 판정: 구절 규칙. 규칙 작성용 표본 142건을 읽고 규칙을 고정한 뒤 게시물 5,000건에 적용했다.
- 특징을 짚거나 이유를 연결한 근거 107행은 모델이 구절을 다시 읽었다. 점검 표본 56건은 규칙 작성 표본과 게시물 ID가 겹치지 않는다.
- 사람 검수는 없다. 첨부 이미지와 영상은 열지 않았다.
- 원본 CSV는 수정하지 않았다.

## 입력

| 파일 | 행의 단위 | 확인한 크기 |
| --- | --- | --- |
| `normalized/x_posts.csv` | 게시물 1개 | 5,000행, `post_id` 5,000 |
| `normalized/x_post_keywords.csv` | 게시물–검색어 1개 | 7,466행, 게시물 5,000 |
| `normalized/x_keywords.csv` | 검색어 1개 | 13개 |
| `normalized/x_post_sources.csv` | 원본 레코드 1개 | 5,000행 |
| `normalized/x_source_files.csv` | 원본 파일 1개 | 5개, 연도별 1,000행 |

연결 키는 `post_id`다. 키워드 7,466행은 게시물 수가 아니다. 작성 시각은 2022-01-01 00:07:15+09:00부터 2026-10-22 21:50:48+09:00까지다. 2026년은 10월 22일까지다. `source_year`와 작성 연도의 불일치는 이 5,000건에서 0이다. 둘의 의미는 다르다.

원본 컬럼에는 게시 유형, 인용 ID, 답글 ID가 없다. 본문이 `RT @`로 시작하는 글도 0건이다. 그래서 원글·인용·답글·리포스트를 관계 유형으로 나누지 않았다. 본문에 보이는 대사와 번역 표시만 작성자 말과 구분했다.

조회수 빈칸은 946건이고 모두 2022년이다. 0으로 바꾸지 않았다.

## 분석에 넣은 글

URL과 계정 멘션을 뺀 뒤, 해시태그 밖의 문장을 본다.

| 언어 | 기준 |
| --- | --- |
| 한국어 중심 | 한글 문장이 있고, 한글이 없는 다른 언어 문장은 없다 |
| 한국어 중심 혼합 | 한글 문장과 다른 언어 문장이 같이 있고, 해시태그 밖 한글이 8자 이상 |
| 다른 언어 중심 | 한글 문장이 없다 |
| 판단 불가 | 해시태그나 기호만 있다 |

분석 대상은 한국어 중심 4,686건과 한국어 중심 혼합 87건, 합계 4,773건이다. 다른 언어 중심 189건과 판단 불가 38건은 반응 집계에서 뺐다. 언어로 국적이나 거주지를 정하지 않았다. 다른 언어 본문은 번역하지 않았다.

이름만 있는 글 3,663건은 언급 집계에 두고, 평가 분모에는 넣지 않는다.

## 치이카와의 역할

다른 이름이 같이 있다는 이유만으로 주인공으로 두지 않는다.

| 역할 | 기준 |
| --- | --- |
| 주인공 | `치이카와가/는` 뒤에 행동·표정·볼·몸이 있다. 상품 이름 바로 뒤는 제외 |
| 작품 | 애니, 영화, 만화, 극장, 팝업, 마켓, 인형·키링처럼 작품이나 상품을 수식 |
| 불명확 | 위 둘이 아닌 이름 |

한 글이 두 역할에 모두 들어갈 수 있다. 역할 막대의 합은 이름 출현 수가 아니다.

## 다섯 축

한 글에 여러 반응이 있으면 근거 행을 여러 개 둔다. 근거 행 수를 게시물 수로 쓰지 않는다.

| 축 | 값 |
| --- | --- |
| 반응 대상 | 특정 캐릭터, 캐릭터 간 관계, 작품·스토리·세계관, 굿즈, 팬아트·번역·편집·창작자, 불명확 |
| 매력 요소 | 외형·표정, 목소리·말투, 성격, 행동·움직임, 관계, 이야기·설정, 상품의 디자인·소재·쓰임, 구체적 이유 없는 호감, 기타·불명확 |
| 감정 | 호감, 웃음·재미, 위로, 공감, 응원·보호 욕구, 비호감·불편, 혼합, 질문·정보·중립, 판단 불가 |
| 행동 | 장면·대사 인용, 번역·팬 창작, 추천·공유 의향, 구매·소장 희망, 구매·획득 경험, 사용·휴대·전시·보관 경험, 방문 희망·경험, 미구매, 행동 표현 없음 |
| 근거 수준 | 직접 이유, 특징을 지목해 평가했으나 이유는 설명하지 않음, 언급 또는 행동만, 판단 불가 |

`귀엽다`만 있으면 구체적 이유 없는 호감이다. 둥근 얼굴이나 짧은 팔다리를 대신 넣지 않는다.

직접 이유는 연결어 왼쪽이 특징이나 호감이고, 오른쪽이 작성자의 감정이나 구매·창작·사용일 때다. 연결어는 아서·어서·해서·여서·워서·뻐서·겨서·싸서·라서·때문에·니까·길래·덕분에다. `있길래` `있어서`처럼 재고만 말하는 왼쪽은 이유로 올리지 않는다. `지만` `는데` 앞은 자른다.

평가어 앞 18자 안에 이름이 하나일 때만 그 캐릭터로 돌린다. 이름이 둘이면 관계 동사나 `케미` `우정` `관계`가 있을 때 캐릭터 간 관계로 두고, 아니면 불명확으로 둔다. `우사기 때문에 웃기다`처럼 이름 바로 뒤에 `때문에`가 있으면 그 이름으로 돌린다.

입고·발매·공구 모집·증정이 있고 작성자의 구매 문장이 없는 글의 호감은 홍보 문구다. 양도는 개인 거래다. 번역 표시만 있는 문장은 작성자 감정이 아니다. 작중 인물이 싫어하는 대상을 작성자 비호감으로 옮기지 않는다.

해시태그 안의 이름은 언급이다. 이름만으로 선호를 만들지 않는다. `#좋아요`가 매장 태그 나열 안에만 있으면 호감으로 세지 않는다.

## 분모

| 집계 | 분모 |
| --- | --- |
| 캐릭터 언급 | 분석 대상 글 중 본문에 그 이름이 확정된 고유 게시물. 같은 이름은 1번. 여러 이름은 각각 |
| 캐릭터 매력·감정 | 그 캐릭터를 작성자가 평가한 고유 게시물. 이유 없는 호감을 포함한다 |
| 행동 | 그 행동 문장이 그 대상에 연결된 고유 게시물. 같은 글에 있기만 한 상품과 호감은 연결하지 않음 |

계정 수는 사람 수가 아니다. 좋아요·리포스트·조회수는 선호 보정에 쓰지 않았다.
